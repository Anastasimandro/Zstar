# Architecture Decision Records

Short records of decisions that shape the project. One file per decision, numbered in order: `NNNN-short-title.md`.

Every closed or newly made decision gets an ADR (see section 9 of [`../DECISIONS.md`](../DECISIONS.md)).

Each ADR has a status, the context, the decision and its consequences. Keep it short. A decision is not edited after the fact: to change it, add a new ADR that supersedes the old one and update the old one's status.
