# Phase prompts

This folder holds the phase prompts that drive the work, one file per phase (for example `phase-0.md`, `phase-1.md`).

- The owner writes and adds a prompt here when a phase starts.
- Work on one phase at a time. Do not start the next one until the current phase meets its acceptance criteria.
- Phase detail lives here, not in [`../DECISIONS.md`](../DECISIONS.md), which only holds closed decisions.
- If a phase prompt contradicts `DECISIONS.md`, stop and tell the owner before continuing.
